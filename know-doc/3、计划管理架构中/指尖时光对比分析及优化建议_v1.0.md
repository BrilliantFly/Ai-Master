#### 4. 番茄工作法模块

**现状**：无专注计时功能

**目标**：实现 25 分钟番茄钟 + 5 分钟休息的标准流程，记录专注数据

**实现方案**：

**新增页面结构**：

```
src/pages/plan/focus/
├── index.vue              # 番茄钟主页面
├── components/
│   ├── TimerRing.vue       # SVG 环形倒计时
│   └── StatsPanel.vue      # 今日专注统计
└── composables/
    └── usePomodoro.ts      # 核心计时逻辑
```

**核心逻辑** — `composables/usePomodoro.ts`：

```typescript
export function usePomodoro() {
  const FOCUS = 25 * 60
  const BREAK = 5 * 60
  const LONG_BREAK = 15 * 60

  const phase = ref<'focus' | 'break'>('focus')
  const remaining = ref(FOCUS)
  const completed = ref(0)
  const isRunning = ref(false)

  const tick = () => {
    remaining.value--
    if (remaining.value <= 0) {
      completePhase()
    }
  }

  const completePhase = () => {
    if (phase.value === 'focus') {
      completed.value++
      phase.value = 'break'
      remaining.value = completed.value % 4 === 0 ? LONG_BREAK : BREAK
      // 记录专注会话
      api.recordFocusSession({ duration: FOCUS })
    } else {
      phase.value = 'focus'
      remaining.value = FOCUS
    }
  }

  return { phase, remaining, completed, isRunning, start, pause, reset }
}
```

**后端** — 新增 `plan_focus_session` 表：

```sql
CREATE TABLE `plan_focus_session` (
  `id`          bigint(20)   NOT NULL AUTO_INCREMENT,
  `user_id`     bigint(20)   NOT NULL COMMENT '用户ID',
  `duration`    int(11)      NOT NULL COMMENT '专注时长(秒)',
  `phase`       tinyint(4)   NOT NULL DEFAULT '0' COMMENT '0专注/1短休/2长休',
  `start_time`  datetime     NOT NULL COMMENT '开始时间',
  `end_time`    datetime     DEFAULT NULL COMMENT '结束时间',
  `create_time` datetime     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_user_date` (`user_id`, `start_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='番茄钟专注记录';
```

**建议首批实施（2天快速见效）**：

1. 习惯打卡页面加入 CSS 柱状趋势图
2. 打卡成功时检测里程碑并弹出成就提示
3. 计划总览首页增加环形进度条和下周预览

这三项不依赖新后端接口、不引入第三方依赖，纯前端改动即可显著缩小与指尖时光的体验差距。
