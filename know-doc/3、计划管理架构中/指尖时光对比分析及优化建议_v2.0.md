#### 6. 番茄工作法模块

**现状**：无专注计时功能

**目标**：实现 25 分钟番茄钟 + 5 分钟休息的标准流程，记录专注数据

**实现方案**：

**新增页面结构**：

```
src/pages/plan/focus/
├── index.vue              # 番茄钟主页面
├── components/
│   ├── TimerRing.vue       # SVG 环形倒计时
│   └── StatsPanel.vue      # 今日专注统计
└── composables/
    └── usePomodoro.ts      # 核心计时逻辑
```

**核心逻辑** — `composables/usePomodoro.ts`：

```typescript
export function usePomodoro() {
  const FOCUS = 25 * 60
  const BREAK = 5 * 60
  const LONG_BREAK = 15 * 60

  const phase = ref<'focus' | 'break'>('focus')
  const remaining = ref(FOCUS)
  const completed = ref(0)
  const isRunning = ref(false)

  const tick = () => {
    remaining.value--
    if (remaining.value <= 0) {
      completePhase()
    }
  }

  const completePhase = () => {
    if (phase.value === 'focus') {
      completed.value++
      phase.value = 'break'
      remaining.value = completed.value % 4 === 0 ? LONG_BREAK : BREAK
      // 记录专注会话
      api.recordFocusSession({ duration: FOCUS })
    } else {
      phase.value = 'focus'
      remaining.value = FOCUS
    }
  }

  return { phase, remaining, completed, isRunning, start, pause, reset }
}
```
