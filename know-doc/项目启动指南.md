# 项目启动指南

当前版本: 1.0.0

---

## 一、快速启动

### 1.1 后端启动

**方式一：命令行直接启动**

```cmd
cd E:\Ai-Master\know-boot

# 启动 know-boot-common (依赖项，无需直接启动)
# 启动 know-boot-api (网关层，端口9002)
start cmd /k java -jar know-boot-api\target\know-boot-api-1.0.0.jar

# 启动 know-boot-system (业务层，端口8082)
start cmd /k java -jar know-boot-system\target\know-boot-system-1.0.0.jar
```

**方式二：Maven 启动**

```cmd
cd E:\Ai-Master\know-boot

# 启动 know-boot-system
cd know-boot-system
mvn spring-boot:run
```

**方式三：IDEA/Eclipse 启动**

1. 打开项目 `E:\Ai-Master\know-boot`
2. 运行 `KnowBootSystemApplication.java` 的 main 方法
3. 或运行 `KnowBootApiApplication.java` 的 main 方法

**方式四：额外CMD窗口启动（推荐）**

```cmd
# 启动 know-boot-system (8082)
start "know-boot-system" cmd /k "cd /d E:\Ai-Master\know-boot\know-boot-system && mvn spring-boot:run"

# 启动 know-boot-api (9002) - 等待system启动完成后再启动
start "know-boot-api" cmd /k "cd /d E:\Ai-Master\know-boot\know-boot-api && mvn spring-boot:run"
```

### 1.2 前端启动

**方式一：已知Vue启动**

```cmd
cd E:\Ai-Master\know-vue

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

**方式二：额外CMD窗口启动（推荐）**

```cmd
# 启动 know-vue (端口3000)
start "know-vue" cmd /k "cd /d E:\Ai-Master\know-vue && npm run dev"
```

**方式三：PM2 生产部署**

```cmd
cd E:\Ai-Master\know-vue

# 构建生产文件
npm run build

# 使用PM2启动
pm2 start ecosystem.config.js
```

## 二、一键启动脚本

### 2.1 启动所有服务

创建 `start-all.bat` 文件：

```bat
@echo off
title 启动所有服务
color 0A

echo ========================================
echo   启动 know 系统所有服务
echo ========================================
echo.

cd /d E:\Ai-Master

echo [1/3] 启动 know-boot-system (8082)...
start "know-boot-system" cmd /k "cd /d E:\Ai-Master\know-boot\know-boot-system && mvn spring-boot:run"
timeout /nobreak /t 10

echo [2/3] 启动 know-boot-api (9002)...
start "know-boot-api" cmd /k "cd /d E:\Ai-Master\know-boot\know-boot-api && mvn spring-boot:run"
timeout /nobreak /t 10

echo [3/3] 启动 know-vue (3000)...
start "know-vue" cmd /k "cd /d E:\Ai-Master\know-vue && npm run dev"

echo.
echo ========================================
echo   所有服务启动完成！
echo.
echo   know-boot-system: http://localhost:8082
echo   know-boot-api:   http://localhost:9002
echo   know-vue:      http://localhost:3000
echo ========================================

pause
```

### 2.2 启动脚本 - 分别启动

创建 `start-system.bat`：

```bat
@echo off
title know-boot-system
cd /d E:\Ai-Master\know-boot\know-boot-system
mvn spring-boot:run
```

创建 `start-api.bat`：

```bat
@echo off
title know-boot-api
cd /d E:\Ai-Master\know-boot\know-boot-api
mvn spring-boot:run
```

创建 `start-vue.bat`：

```bat
@echo off
title know-vue
cd /d E:\Ai-Master\know-vue
npm run dev
```

### 2.3 停止所有服务

创建 `stop-all.bat`：

```bat
@echo off
title 停止所有服务
color 0C

echo ========================================
echo   停止 know 系统所有服务
echo ========================================

taskkill /F /FI "WINDOWTITLE eq know-boot-system*" /T
taskkill /F /FI "WINDOWTITLE eq know-boot-api*" /T
taskkill /F /FI "WINDOWTITLE eq know-vue*" /T
taskkill /F /IM java.exe /T
taskkill /F /IM node.exe /T

echo.
echo   所有服务已停止！
echo ========================================

pause
```

## 三、端口配置

### 3.1 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| know-boot-system | 8082 | 业务接口服务 |
| know-boot-api | 9002 | 网关服务 |
| know-vue | 3000 | 前端开发服务 |
| MySQL | 3306 | 数据库 |
| Redis | 6379 | 缓存 |

### 3.2 修改端口

**后端端口配置**：`know-boot-system/src/main/resources/application.yml`

```yaml
server:
  port: 8082
```

**前端端口配置**：`know-vue/vite.config.ts`

```typescript
export default defineConfig({
  server: {
    port: 3000
  }
})
```

## 五、常见问题

### 5.1 端口被占用

```cmd
# 查看占用端口的进程
netstat -ano | findstr "8082"

# 终止进程
taskkill /PID <进程ID> /F
```

### 5.2 Maven 依赖下载慢

修改 `settings.xml`：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### 5.3 Node_modules 问题

```cmd
# 删除重新安装
rd /s /q node_modules
npm install
```
