## 二、详细差异清单（按优先级排序）

### 🔴 P0 — 必须补（严重影响体验）

#### 1. 数值型习惯追踪（量化打卡）
- **现状**: 仅支持二值（完成/未完成），`target`/`unit` 字段存在但未充分使用
- **指尖时光**: 支持一次打卡输入数值（如喝水量 500ml、跑步 5km），图表按数值累计展示
- **改动量**: 中
- **文件**: checkin.html
- **方案**: 
  - 打卡弹窗中添加数值输入（默认=target，可修改）
  - 记录存储改为 `{date, value, note}` 而非仅日期
  - 图表按数值累计而非次数
  - 周进度条按 target×freqTarget 计算完成率

#### 2. 休息日 / Streak 保护
- **现状**: 漏打一天 streak 即断，无缓冲
- **指尖时光**: 支持设置每周休息日（如周日自动跳过），部分版本有补签卡
- **改动量**: 小
- **文件**: checkin.html
- **方案**:
  - Goal 模型增加 `restDays: []`（一周中哪些天休息）
  - `getStreak()` 计算时跳过休息日
  - UI 显示休息日标记

#### 3. 年度热力图（GitHub 风格）
- **现状**: 仅月度日历（5 级色阶）
- **指尖时光**: 月视图热力图 + 年视图贡献图
- **改动量**: 中
- **文件**: checkin.html（统计 tab）
- **方案**:
  - renderStats() 中增加 `.year-grid`（12×31 网格）
  - 5 级颜色强度 + 图例
  - 年视图悬浮显示具体日期

#### 4. 云同步 / 数据备份
- **现状**: 纯 localStorage，清除浏览器数据即丢失
- **指尖时光**: iCloud / 自有云实时同步，多端协同
- **改动量**: 大
- **文件**: shared.js + 后端
- **方案**:
  - 短期：localStorage + JSON 文件手动导入/导出（已有导出，加导入）
  - 长期：接入 Firebase / Supabase 实时同步

### 🟡 P1 — 建议补（体验有明显提升）

#### 5. 更多日程视图（年视图 + 议程视图）
- **现状**: 日/周/月三种视图
- **指尖时光**: 日/周（横纵）/月/年/列表五种视图
- **改动量**: 中
- **文件**: schedule.html
- **方案**:
  - 年视图: 12 宫格缩略月历（36×36 网格），有任务日期蓝色圆点
  - 议程视图: 连续滚动列表，按日期分组，无日期间隔

#### 6. 打卡时数值输入 + 备注增强
- **现状**: prompt() 弹窗输入备注，纯文本
- **指尖时光**: 富文本笔记 + 图片附件
- **改动量**: 中
- **文件**: checkin.html
- **方案**:
  - 打卡弹窗改成自定义 modal（非 prompt）：
    - 数值输入（若 goal.tracking_type === 'numeric'）
    - 备注文本区
    - 可选项：拍照/相册图片

#### 7. 白噪音 + 番茄锁机
- **现状**: 番茄钟仅有倒计时 + 通知
- **指尖时光**: 内置白噪音（雨/森林/海浪/篝火）+ 专注锁屏
- **改动量**: 中
- **文件**: schedule.html（Pomodoro 面板扩展）
- **方案**:
  - 番茄面板增加白噪音选择器（Web Audio API 生成自然音效）
  - 锁机: 全屏遮挡层+退出确认（纯前端模拟）

#### 8. 节假日 / 农历日历
- **现状**: 仅公历日期
- **指尖时光**: 中国节日节气 + 农历 + 择日
- **改动量**: 中
- **文件**: schedule.html（日历网格）+ shared.js
- **方案**:
  - 嵌入农历数据（静态 JSON 映射 2025-2030）
  - 日历单元格增加农历小字
  - 节日红点标记

#### 9. 倒数日 / 纪念日功能
- **现状**: 无
- **指尖时光**: 倒数日（高考倒计时等）+ 正数日（纪念日等）+ 环形进度
- **改动量**: 中
- **文件**: 新页面或嵌入 schedule.html
- **方案**:
  - schedule.html 中增加"倒数日"tab/面板
  - 支持创建目标日期、名称、图标
  - 环形 SVG 进度条展示时间进度

### 🔵 P2 — 值得补（提升竞争力）

#### 10. 更多主题（18+）
- **现状**: 7 套主题（white/dark/warm/aurora/purple/glass/orangold）
- **指尖时光**: 18+ 主题 + 马卡龙配色 + 卡通皮肤
- **改动量**: 小-中
- **文件**: theme.js + styles.css
- **方案**: 增加 8-10 套新主题（马卡龙粉/薄荷/薰衣草/奶茶/抹茶/浆果/奶油/海洋）

#### 11. 时间追踪图表增强
- **现状**: SVG 柱状图（分类统计）
- **指尖时光**: 饼图 + 条形图 + 时间分配报表
- **改动量**: 小
- **文件**: schedule.html（renderTimeTrack）
- **方案**:
  - 增加饼图（SVG circle 扇形）
  - 增加总时间/日均时间头部统计

#### 12. 课程表功能
- **现状**: 无
- **指尖时光**: 定制课程表 + 拍照导入课表
- **改动量**: 中
- **文件**: 新页面嵌入到 schedule
- **方案**:
  - schedule 中增加"课程表"tab
  - 周视图网格预置时间段（08:00-21:00）
  - 可编辑每格课程名/地点/老师

#### 13. 打卡统计增强
- **现状**: 折线图 + 周柱状图 + 月热力图 + 成就徽章
- **指尖时光**: 完成率趋势 + 时间分配 + 自动复盘报告
- **改动量**: 小-中
- **文件**: checkin.html（renderStats）
- **方案**:
  - 增加"本月每日完成率"折线
  - 增加分类占比图（各分类习惯占比）
  - 增加简短文字复盘（如"本月完成率 85%，最佳连续 12 天"）

#### 14. 数据导入功能
- **现状**: 仅有 JSON 导出
- **指尖时光**: 导出（VIP）+ 导入
- **改动量**: 小
- **文件**: checkin.html + schedule.html
- **方案**:
  - 增加文件选择器导入 JSON
  - 验证数据结构后合并到 localStorage
  - 显示导入结果（新增/覆盖数量）

## 四、优先级建议

### 短期（1-2 天）
1. **数值型打卡** — 最大的功能缺失，直接影响打卡体验
2. **休息日保护 Streak** — 小改动，极大提升用户留存
3. **打卡弹窗增强** — 替换原生 prompt 为自定义 modal
4. **数据导入功能** — 补全导出/导入闭环
5. **优化成就徽章** — 增加进度指引

### 中期（3-5 天）
6. **年度热力图** — 显著提升统计页视觉冲击
7. **白噪音 + 番茄增强** — 丰富专注体验
8. **更多主题（15+）** — 低投入高颜值回报
9. **节假日/农历日历** — 贴合中国用户习惯
10. **倒数日功能** — 完整生活工具链

### 长期（1-2 周）
11. **云同步** — 最严重的基础设施缺失
12. **PWA / 桌面小组件** — 触及更多使用场景
13. **更多视图（年/议程）** — 追平日程管理专业度
14. **课程表 / 笔记 / 记账** — 扩展为全场景工具

## 五、总结

| 维度 | 评价 |
|------|------|
| 核心功能完整度 | ⭐⭐⭐⭐（打卡和日程基础扎实） |
| UI/UX 设计 | ⭐⭐⭐⭐（7 主题 + 动画细腻） |
| 数据分析 | ⭐⭐⭐（趋势图 + 热力图 + 足迹，缺年视图） |
| 数据安全 | ⭐⭐（纯 localStorage，风险较高） |
| 个性化 | ⭐⭐⭐（7 主题 + 自定义色 + 背景图） |
| 功能广度 | ⭐⭐⭐（缺倒数日/笔记/记账/课程表） |
| 移动端适配 | ⭐⭐⭐⭐（响应式 + 触控 + PWA 潜力） |

**最大差异化机会**: 实现 **云同步 + 数值型打卡 + 年热力图** 即可在功能上超越指尖时光免费版。

> 指尖时光 VIP（68 元/年）的核心卖点是云同步、无限制操作、数据导出。如果我们免费提供这些，配合 PWA 无需安装，就是一个非常有竞争力的替代品。
