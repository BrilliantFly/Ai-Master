# 暖色主题「橘金」设计文档

## 概述
第7个主题 — 米白底色 × 暖橘 + 琥珀金混合的温暖明亮风格。

## 色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 米白底 | `#faf6f0` | 页面背景 |
| 米白-浅 | `#f5f0eb` | 次要背景、渐变 |
| 暖橘主色 | `#E87A5D` | 主强调色、选中态 |
| 暖橘-浅 | `#F5A080` | 图标渐变、hover态 |
| 金色主色 | `#D4A04A` | 辅强调色、星级高亮 |
| 金色-浅 | `#E8C46A` | 图标渐变、hover态 |
| 文字-深 | `#5a4a3a` | 主要文字 |
| 文字-浅 | `#b0a090` | 次要文字、占位符 |
| 衬色 | `#8B7355` | 标签文字、辅助色 |
| 边框 | `#ede4d8` | 卡片边框 |
| 卡片表面 | `rgba(255,255,255,0.6)` | 卡片、输入框背景 |
| 橘→金渐变 | `linear-gradient(135deg, #E87A5D, #D4A04A)` | 按钮、选中态tabs |

## 设计原则
- **暖而明亮**：米白底色不刺眼，暖橘和金色带来温暖活力
- **柔和质感**：卡片使用半透明白背景 + 细腻边框，无重阴影
- **双色点缀**：暖橘做主色（活力），金色做辅色（质感），渐变贯穿两者
- **干净留白**：组件间有充分间距，不拥挤

## 组件规范
- **顶部导航**：半透明白底部，橘金渐变图标
- **搜索栏**：半透明白底 + 圆角 + 金色搜索图标
- **分类标签**：选中态橘金渐变背景，未选中淡色底 + 对应色文字
- **内容卡片**：半透明白底 + `1px solid #ede4d8` 边框 + 无阴影
- **按钮**：主要按钮橘金渐变（带微阴影），次要按钮 `#ede4d8` 底
- **输入框**：半透明白底 + 金色图标装饰
- **底部tab**：选中态金色文字，未选中 `#b0a090`
- **标签**：橘/金色文字 + 对应 0.08 透明度背景

## 文件结构
- CSS: `styles.css` — 新增 `html[data-theme="orangold"]` 变量块 + 组件覆盖
- 主题面板: 所有6个HTML新增「橘金」选项
- Swatch: `.sw-orangold { background: linear-gradient(135deg, #E87A5D, #D4A04A); }`
