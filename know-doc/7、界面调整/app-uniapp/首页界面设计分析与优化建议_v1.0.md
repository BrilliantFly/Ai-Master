## 二、当前设计问题诊断

### 2.1 结构问题

| 问题 | 描述 | 严重度 |
|------|------|:------:|
| **缺少视觉层次** | 所有卡片相同样式（`premium-card`），无主次之分 | 🔴 |
| **信息密度过高** | 一屏塞了 5 个区块，用户不知该看哪里 | 🔴 |
| **Hero 区浪费** | 3 个数字卡片无上下文关联，用户无法一眼感知"今天怎么样" | 🔴 |
| **快捷入口过于单薄** | 只有 2 个入口，4 列变 2 列，空间利用率低 | 🟡 |
| **月度概况无可视化** | 纯数字无环图/进度条，枯燥不直观 | 🟡 |
| **今日提醒无交互** | 只展示，不能直接完成/标记 | 🟡 |
| **空状态无引导** | 无数据时"今天还没有日程安排"显得冷清 | 🟢 |
| **缺少个性感** | 没有用户头像/问候语/背景装饰 | 🟢 |

### 2.2 设计细节问题

| 问题 | 具体表现 |
|------|---------|
| **内边距不一致** | `padding: 24rpx 16px 160rpx` — 混用了 rpx 和 px |
| **间距过大** | `margin-bottom: 16px` 使用 px 而非 rpx，不同屏幕表现不一致 |
| **阴影平淡** | `premium-card` 使用了 `--shadow-md` 但卡片之间缺少视觉区分 |
| **缺少动效** | 页面加载时所有元素同时出现，无渐入/错位动画 |
| **图标简陋** | 使用 emoji 而非 SVG 图标，在不同设备上渲染不一致 |
| **颜色单调** | 整体只有黑白灰 + 主色调，缺少语义色点缀 |
| **无数据状态冷清** | empty-tip 只有一行灰色文字 |

## 三、设计参考来源

### 参考一：指尖时光（App Store 评分 4.8）

**可借鉴的设计元素**：

| 元素 | 描述 | 参考价值 |
|------|------|:--------:|
| **欢迎语** | 顶部"早上好/下午好，用户名" + 日期 | 增加亲切感 |
| **环图进度** | 圆形进度展示今日完成率 | 可视化替代纯数字 |
| **分类标签** | 习惯按"健康/学习/运动/情感"四类展示 | 增加信息结构 |
| **卡面色块** | 渐变色背景区分不同模块 | 视觉层次感 |
| **留白控制** | 间距适中，不拥挤不空旷 | 呼吸感 |

### 参考二：多仪 Duoyi（Flutter 开源效率工具）

**可借鉴的设计元素**：

| 元素 | 描述 | 参考价值 |
|------|------|:--------:|
| **综合评分模块** | 今日效率综合评分 + 环图 | 一图胜千言 |
| **模块 Tab 切换** | 主页用卡片式 Tab 而非全部堆叠 | 降低信息密度 |
| **主题联动** | 背景图 + 主题色 + 问候语联动 | 个性化 |
| **习惯热力图** | GitHub 风格日历方块 | 习惯概览直观 |

### 参考三：现代移动仪表盘设计趋势

| 趋势 | 说明 |
|------|------|
| **玻璃态 (Glassmorphism)** | 毛玻璃背景叠加，层次感强 |
| **微交互 (Micro-interaction)** | 点击涟漪、加载骨架屏、数字滚动动画 |
| **卡片分层 (Card Hierarchy)** | 主卡更大/带渐变/带阴影，次要卡简化 |
| **数据可视化优先** | 环图 > 进度条 > 数字 > 文字 |
| **内容区块化 (Modular)** | 各区块独立可折叠/可拖拽 |

## 五、色彩与视觉规范建议

| 层级 | 用途 | 建议样式 | 现有 |

## 六、建议实施路线

| 等级 | 内容 | 工期 | 效果 |
|:----:|------|:----:|:----:|
| 🟢 L1 | 渐变 Header + 环图 + 动效 + 空状态 | 1 天 | 立即提升视觉品质 |
| 🟡 L2-A | Tab 式布局或卡片层级布局 | 1.5 天 | 信息组织更清晰 |
| 🟡 L2-B | 待办 checkbox 交互 + 习惯快打卡 | 1 天 | 交互感增强 |
| 🔴 L3 | 全面重构（结合统计独立页） | 2 天 | 最佳效果 |

**推荐路径**：
1. 先做 🟢 L1（1天）— 最快见效
2. 同时推进统计独立页（参考《统计功能独立页面设计方案》）
3. 统计页做好后，再做 🟡 L2（简化首页数据，增加快捷入口）
