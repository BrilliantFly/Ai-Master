## 二、问题诊断（按首页实际角色）

### 2.1 布局层级问题

| # | 问题 | 描述 | 严重度 |
|:-:|------|------|:------:|
| 1 | **首页角色模糊** | banner 和菜单都是入口，推荐和工具也是入口，4 种入口形式混在一起 | 🔴 |
| 2 | **Banner 空间低效** | 3 个固定 banner 占 320rpx 顶屏，首次加载可见内容极少 | 🔴 |
| 3 | **菜单缺少分类** | 9+ 个菜单项平铺，用户找目标要扫读，无视觉分组 | 🟡 |
| 4 | **"推荐"和"工具"界限模糊** | 甘特图是工具、客户管理是推荐？用户无法理解分类逻辑 | 🟡 |
| 5 | **缺少动态数据** | 首页全是静态入口，没有待处理数量/告警数等业务指标 | 🟡 |

### 2.2 视觉与交互问题

| # | 问题 | 描述 | 严重度 |
|:-:|------|------|:------:|
| 6 | **问候区无人性化** | 静态"你好"，没有用户昵称/天气/时间问候 | 🟢 |
| 7 | **emoji 作为图标** | 📹📅🎯 等 emoji 在不同系统渲染差异大 | 🟢 |
| 8 | **间距混用单位** | `padding: 24rpx 40rpx` 和 `16px` 混用 px/rpx | 🟢 |
| 9 | **无加载骨架屏** | 页面内容瞬间全部出现，等待体验差 | 🟢 |
| 10 | **通知横幅样式过时** | 黄色 warning 色 banner 像错误提示 | 🟢 |

const greetingText = computed(() => {

  if (hour < 14) return '中午好'

#### 关键改动

| 改动项 | 现状 | 改后 |
|--------|------|------|
| **首页命名** | 无标题 | "工作台" |
| **首屏重点** | Banner 轮播 | 待处理事项聚合（告警/待办/客户） |
| **菜单展示** | 固定 4 列快速入口 | 可自定义 5 列常用功能 + 拖拽排序 |

| **信息展示** | 推荐 + 工具 两个区域 | 合并为"动态信息"一栏 |
| **数据驱动** | 纯静态 | 接口返回待办数量、告警数等 |

#### 用户可自定义菜单（Level 3 亮点）

```typescript
// stores/home.ts
export const useHomeStore = defineStore('home', () => {
  const shortcuts = ref<HomeDisplayItem[]>([])

  // 从本地存储读取用户自定义快捷菜单
  const loadShortcuts = () => {
    const cached = uni.getStorageSync('home_shortcuts')
    shortcuts.value = cached ? JSON.parse(cached) : defaultShortcuts
  }

  // 保存用户自定义快捷菜单
  const saveShortcuts = (items: HomeDisplayItem[]) => {
    shortcuts.value = items
    uni.setStorageSync('home_shortcuts', JSON.stringify(items))
  }

  // 添加快捷方式
  const addShortcut = (item: HomeDisplayItem) => {
    if (shortcuts.value.length >= 8) return
    shortcuts.value.push(item)
    saveShortcuts(shortcuts.value)
  }

  return { shortcuts, loadShortcuts, saveShortcuts, addShortcut }
})
```
