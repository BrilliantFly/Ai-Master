> 对比分析：know-uniapp vs 指尖时光

## 一、现状总览

|------|---------|---------|
| **日程** | 月视图日历(静态HTML)、统计卡片、四象限视图(JS筛选)、日程列表(硬编码)、7主题 | 数据持久化、CRUD交互、多视图切换、重复/提醒、分类管理、搜索、拖拽排序 |

## 二、日程模块优化项

### P0 — 核心缺失


#### 2. 添加/编辑/删除交互
**现状**：日程列表只读，"+"按钮无功能，点击日程无响应。  
**目标**：弹窗表单支持创建和编辑日程。  
**方案**：
- 底部/中间弹出表单：标题、日期、起止时间、分类、象限归属、备注
- 编辑：点击现有日程卡片打开同一表单，预填数据
- 删除：左滑显示删除按钮，或长按弹出删除确认

---

### P1 — 体验增强

#### 3. 日 / 周 / 月 视图切换
**现状**：仅月视图，硬编码日期格子。  
**目标**：支持日、周、月三种视图模式自由切换。  
**方案**：
```
[今日] [日] [周] [月]  ← 视图切换器
```
- **日视图**：24h 时间轴，按时间段展示任务
- **周视图**：7 列网格，每日下方显示任务条
- **月视图**：保留现有日历网格，但动态生成日期 + 任务圆点标记
- 统一基于 `scheduleData` 渲染，切换视图仅改变呈现方式

#### 4. 四象限交互增强
**现状**：仅筛选视图，不可拖拽，不可操作任务。  
**目标**：四象限内可直接管理任务。  
**方案**：
- 每个象限内列出该分类的任务（精简卡片，无时间轴）
- 拖拽任务到其他象限 → 自动更新 `task.quadrant`
- 点击任务 → 打开编辑弹窗
- 象限 Tab 切换与列表视图联动

---

### P2 — 进阶功能

#### 5. 重复日程 & 提醒
**现状**：无。  
**目标**：支持重复规则和提前提醒。  
**方案**：
- 重复：不重复 / 每天 / 每个工作日 / 每周 / 每两周 / 每月
- 提醒：不提醒 / 当天 9:00 / 提前 15 分钟 / 提前 30 分钟 / 提前 1 小时 / 提前 1 天
- 数据字段：`repeat: 'daily' | 'weekday' | 'weekly' | null`，`remind: 15 | 30 | 60 | null`

#### 6. 分类/标签管理系统
**现状**：标签硬编码（`tag-danger`、`tag-warning`）。  
**目标**：用户自定义分类，日程列表可按分类过滤。  
**方案**：
```
categories: [
  { id, name, color, icon }
]
```
- 预设：工作、学习、生活、健康、其他
- 添加日程时选择分类，分类颜色作为卡片标识色
- 列表头部增加分类筛选条

---

### P3 — 效率工具

#### 7. 搜索功能
**现状**：首页搜索框只占位无功能。  
**目标**：搜索框输入即搜索日程标题和备注。  
**方案**：
- 监听输入事件，按 `title` 和 `note` 模糊匹配
- 搜索结果实时展示在原列表位置
- 搜索高亮匹配文字

#### 8. 拖拽排序
**现状**：按固定时间顺序排列。  
**目标**：日程卡片支持拖拽调整顺序（时间不变，顺序优先级变化）。  
**方案**：
- HTML5 Drag & Drop 或 touch 事件
- 排序字段：`sortOrder: number`
- 主要用于"待处理"视图，手动调整执行顺序

## 三、打卡模块优化项

### P0 — 从零搭建

#### 9. 新建独立打卡页面 `checkin.html`
**现状**：无独立打卡页，首页"习惯"图标指向日程页面（错误）。  
**目标**：新建 `checkin.html`，作为打卡模块独立入口，加入底部导航栏。  
**页面结构**：
```
┌─ 顶部：今日摘要（打卡数/总目标数 + 连续天数）
├─ 目标列表（每个目标一张卡片）
│   ├─ 目标名称 + 周期标识
│   ├─ 今日打卡按钮（已打/未打）
│   └─ 本周完成进度条
├─ 底部 Tab：打卡记录 / 统计 / 管理
└─ FAB 按钮：新建目标
```

#### 10. 目标创建与管理
**现状**：无。  
**目标**：用户可创建习惯目标，设定周期和提醒。  
**方案**：
```
goals: [
  {
    id, name, icon,
    repeat: 'daily' | 'weekday' | 'weekly',
    remindTime: '09:00',
    motto: '激励语',
    created: '2026-06-01'
  }
]
```
- 创建弹窗：名称、图标选择、重复周期、提醒时间、激励语
- 列表展示所有进行中的目标
- 左滑可编辑/删除/归档目标

#### 11. 每日打卡 + 连续天数
**现状**：无。  
**目标**：点击打卡按钮记录今日完成，自动计算连续天数。  
**方案**：
```
checkinRecords: {
  'goal_1': ['2026-06-01', '2026-06-02', ...],  // 打卡日期数组
  'goal_2': [...]
}
```
- 打卡操作：点击目标卡片的"打卡"按钮 → 追加今日日期
- 取消打卡：再次点击取消（仅限当天）
- 连续天数：从今天往前数连续有打卡记录的天数
- 首页摘要：显示"今日已打卡 X/Y 个目标"

---

### P1 — 可视化

#### 12. 月度打卡日历
**现状**：无。  
**目标**：月视图上标记打卡日，直观展示本月执行情况。  
**方案**：
- 复用日程页的月日历组件
- 每个日期格子内，用圆点/对勾标记当天各目标的完成状态
- 可选：热力图风格（颜色深浅 = 完成率高低）

#### 13. 完成率统计图表
**现状**：无。  
**目标**：周/月完成率柱状图，趋势折线图。  
**方案**：
- 使用 Canvas 或简单 CSS 柱状图
- 周统计：7 天柱状图，每天 = 完成目标数 / 总目标数
- 月统计：30 天趋势折线图
- 展示在打卡页面的"统计"Tab 下

---

### P2 — 激励系统

#### 14. 成就徽章
**现状**：无。  
**目标**：达成里程碑时解锁对应徽章。  
**方案**：
```
achievements: [
  { id, name, icon, condition: 'streak_7', desc: '连续打卡7天' },
  { id, name, icon, condition: 'streak_21', desc: '连续打卡21天' },
  { id, name, icon, condition: 'streak_100', desc: '连续打卡100天' },
  { id, name, icon, condition: 'total_365', desc: '累计打卡365天' },
]
```
- 在"我的"页面或个人中心展示已获得徽章
- 达成时弹出 congratulation 提示

#### 15. 打卡提醒推送
**现状**：无。  
**目标**：在目标设定的提醒时间发送通知。  
**方案**：
- 利用 `Notification API` 或 Web 端 Service Worker
- 提醒文案可自定义（目标创建时的激励语）
- 注意：Web 端推送需用户授权，移动端原生需插件

## 四、补充模块

### P3 — 番茄钟
**现状**：无。  
**目标**：25 分钟专注 + 5 分钟休息的番茄计时器。

- 数据量少，可快速实现

### P4 — 倒数日
**现状**：无。  
**目标**：记录重要日期的倒计时。  
**方案**：
- 可归入日程模块，或作为独立轻量组件
- 数据：`{ title, targetDate, remind }`
- 展示：距目标日期还有 X 天

## 七、技术要点

- **数据层**：`localStorage` 封装 `DataStore`，统一读写接口
- **视图切换**：CSS `display` 控制日/周/月容器显隐，JS 动态填充
- **拖拽**：HTML5 Drag & Drop API（桌面）+ touch 事件（移动端）
- **图表**：纯 CSS 柱状图 + Canvas 折线图（无第三方依赖）
- **弹窗**：CSS 居中弹窗 + 半透明遮罩层，表单数据双向绑定
- **主题**：复用现有 `data-theme` + CSS 变量体系，新增组件直接引用
