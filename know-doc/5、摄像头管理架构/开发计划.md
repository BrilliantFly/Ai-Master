# 摄像头管理系统开发计划

## 项目概述
- **版本**: 1.0.0
- **技术栈**: uniapp + Spring Boot (微服务架构)
- **目标**: 移动端摄像头管理，实现设备发现、实时浏览、录像截图功能
- **模块**: know-boot-camera (独立微服务模块，端口8085)

### 阶段二：WIFI配网模块 (预计2天) - 前端

| 序号 | 任务 | 文件/模块 | 功能 |
|------|------|-----------|------|
| 2.1 | WIFI状态获取 | wifi.ts - getConnectedWifi() | 获取当前WIFI信息 |
| 2.2 | WIFI列表 | wifi.ts - getWifiList() | 获取可连接WIFI列表(需定位权限) |
| 2.3 | 配网组件 | WiFiConfig.vue | 输入WIFI名称和密码 |
| 2.4 | UDP广播配网 | wifiConfig.js - broadcastConfig() | 发送配网信息到摄像头 |
| 2.5 | 配网状态页 | WiFiConfigStatus.vue | 显示配网进度 |

**核心代码结构**:
```javascript
// wifiConfig.js
class WiFiConfig {
  async startConfig(ssid, password)  // 开始配网
  broadcastConfig(data)               // UDP广播
  waitForDeviceOnline(timeout)      // 等待设备上线
}
```

##注意事项

1. **网络限制**: 局域网完全可行，远程需要P2P或VPN
2. **认证安全**: 切勿使用默认密码，注意设备限流
3. **隐私合规**: 禁止在隐私场所安装，需遵守当地法规
4. **兼容厂商**: 主要支持ONVIF、Hikvision、Dahua通用协议
5. **服务端口**: know-boot-camera 默认端口 8085
