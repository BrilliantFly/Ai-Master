当前版本: 1.0.0

## 一、概述

本文档介绍多租户权限系统的配置和使用方法，包括租户管理、租户切换、数据隔离等核心功能。

### 1.1 核心特性

- **多租户隔离**：基于 MyBatis Plus 拦截器实现 SQL 级别数据隔离
- **动态租户切换**：用户可在线切换所属租户
- **权限继承**：用户在租户内继承角色权限
- **租户管理员**：支持租户级别管理员

## 二、数据库设计

### 2.1 核心表结构

#### 租户表 (sys_tenant)

```sql
CREATE TABLE sys_tenant (
  id BIGINT PRIMARY KEY COMMENT '主键',
  name VARCHAR(100) NOT NULL COMMENT '租户名称',
  code VARCHAR(50) NOT NULL COMMENT '租户编码',
  logo VARCHAR(255) COMMENT 'Logo地址',
  status TINYINT DEFAULT 1 COMMENT '状态 [0:停用,1:正常]',
  expire_time DATETIME COMMENT '过期时间',
  create_by VARCHAR(32) COMMENT '创建人',
  create_time DATETIME COMMENT '创建时间',
  update_by VARCHAR(32) COMMENT '更新人',
  update_time DATETIME COMMENT '更新时间',
  del_flag TINYINT DEFAULT 0 COMMENT '删除标志',
  UNIQUE KEY uk_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='租户表';
```

#### 用户租户关联表 (sys_tenant_user)

```sql
CREATE TABLE sys_tenant_user (
  id BIGINT PRIMARY KEY COMMENT '主键',
  user_id BIGINT NOT NULL COMMENT '用户ID',
  tenant_id BIGINT NOT NULL COMMENT '租户ID',
  is_admin TINYINT DEFAULT 0 COMMENT '是否租户管理员 [0:否,1:是]',
  status TINYINT DEFAULT 1 COMMENT '状态 [1:正常]',
  create_by VARCHAR(32) COMMENT '创建人',
  create_time BIGINT COMMENT '创建时间',
  UNIQUE KEY uk_user_tenant (user_id, tenant_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户租户关联表';
```

#### 数据权限配置表 (sys_data_permission)

```sql
CREATE TABLE sys_data_permission (
  id BIGINT PRIMARY KEY COMMENT '主键',
  role_id BIGINT NOT NULL COMMENT '角色ID',
  dept_ids VARCHAR(500) COMMENT '可见部门ID列表',
  data_scope TINYINT DEFAULT 1 COMMENT '数据范围 [1:全部,2:本部门,3:本部门及子部门,4:仅本人]',
  create_by VARCHAR(32) COMMENT '创建人',
  create_time DATETIME COMMENT '创建时间',
  update_by VARCHAR(32) COMMENT '更新人',
  update_time DATETIME COMMENT '更新时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据权限配置表';
```

## 三、核心组件

### 3.1 TenantContextHolder 租户上下文

**文件位置**：`know-boot-common/src/main/java/com/know/knowboot/context/TenantContextHolder.java`

**功能**：在当前线程中存储和获取租户信息

```java
// 获取当前租户ID
Long tenantId = TenantContextHolder.getTenantId();

// 获取租户编码
String tenantCode = TenantContextHolder.getTenantCode();

// 设置租户信息
TenantContextHolder.setTenant(tenantId, tenantCode, isAdmin);

// 清除租户上下文
TenantContextHolder.clear();

// 检查是否是租户管理员
boolean isAdmin = TenantContextHolder.isTenantAdmin();

// 检查是否是系统级租户（不受租户过滤影响）
boolean isSystem = TenantContextHolder.isSystemTenant();
```

### 3.2 CustomTenantLineHandler 多租户处理器

**文件位置**：`know-boot-system/src/main/java/com/know/knowboot/config/CustomTenantLineHandler.java`

**功能**：实现 MyBatis Plus 的 TenantLineHandler 接口，自动在 SQL 中注入 tenant_id 条件

**不进行租户过滤的表**（全局表）：

| 表名 | 说明 |
|------|------|
| sys_tenant | 租户表 |
| sys_tenant_user | 用户租户关联 |
| sys_dict_type | 字典类型 |
| sys_dict_data | 字典数据 |
| sys_permission | 权限表 |
| sys_role_permission | 角色权限关联 |
| sys_oper_log | 操作日志 |
| sys_login_log | 登录日志 |
| sys_user | 用户表 |
| sys_role | 角色表 |

### 3.3 MybatisPlusConfig 配置

**文件位置**：`know-boot-system/src/main/java/com/know/knowboot/config/MybatisPlusConfig.java`

**配置多租户插件**：

```java
@Bean
public TenantLineInnerInterceptor tenantLineInnerInterceptor() {
    return new TenantLineInnerInterceptor(new CustomTenantLineHandler());
}
```

### 4.2 登录时设置租户上下文

```java
// LoginServiceImpl.java - 登录成功后设置租户上下文
public LoginResult login(String username, String password) {
    // 1. 验证用户名密码
    SysUser user = sysUserService.getByUsername(username);
    
    // 2. 获取用户当前租户
    SysTenant tenant = sysTenantService.getUserCurrentTenant(user.getId());
    if (tenant != null) {
        // 3. 设置租户上下文
        TenantContextHolder.setTenant(
            tenant.getId(), 
            tenant.getCode(), 
            isAdmin(user.getId(), tenant.getId())
        );
    }
    
    // 4. 生成Token
    String token = StpUtil.login(user.getId(), true);
    
    // 5. 返回结果
    return new LoginResult(token, user, tenant);
}
```


#### 租户切换组件

```vue
<template>
  <el-dropdown @command="handleSwitchTenant">
    <span class="el-dropdown-link">
      {{ currentTenant.name }}<i class="el-icon-arrow-down el-icon--right"></i>
    </span>
    <el-dropdown-menu slot="dropdown">
      <el-dropdown-item 
        v-for="tenant in tenantList" 
        :key="tenant.id" 
        :command="tenant.id">
        {{ tenant.name }}
      </el-dropdown-item>
    </el-dropdown-menu>
  </el-dropdown>
</template>

<script>
export default {
  data() {
    return {
      tenantList: [],
      currentTenant: {}
    }
  },
  async mounted() {
    await this.loadTenantList()
  },
  methods: {
    async loadTenantList() {
      const res = await getUserTenantList()
      this.tenantList = res.result || []
      const current = await getCurrentTenant()
      this.currentTenant = current.result || {}
    },
    async handleSwitchTenant(tenantId) {
      await switchTenant(tenantId)
      this.$message.success('切换成功')
      await this.loadTenantList()
      // 刷新页面数据
      this.$router.go(0)
    }
  }
}
</script>
```

### 6.2 角色权限配置

```sql
-- 超级管理员拥有所有租户权限
INSERT INTO sys_role_permission (role_id, permission_id) 
SELECT 1, id FROM sys_permission WHERE permission_code LIKE 'tenant:%';

-- 租户管理员拥有部分权限
INSERT INTO sys_role_permission (role_id, permission_id)
```

## 八、常见问题

### 8.1 租户数据未隔离

**问题**：数据查询没有按租户过滤

**排查步骤**：
1. 检查 TenantContextHolder 是否正确设置
2. 检查表是否有 tenant_id 字段
3. 检查 CustomTenantLineHandler 是否配置
4. 检查是否在忽略表列表中

**解决方案**：

```java
// 确保登录后设置租户上下文
TenantContextHolder.setTenant(tenant.getId(), tenant.getCode(), false);

// 确保 MybatisPlusConfig 中配置了插件
@Bean
public TenantLineInnerInterceptor tenantLineInnerInterceptor() {
    return new TenantLineInnerInterceptor(new CustomTenantLineHandler());
}
```

### 8.2 租户切换失败

**问题**：切换租户后数据未变化

**排查步骤**：
1. 检查 Token 是否刷新
2. 检查前端是否重新请求数据
3. 检查后端上下文是否更新

**解决方案**：

```typescript
// 前端：切换成功后刷新页面
await switchTenant(tenantId)
uni.reLaunch({ url: '/pages/index/index' })
```

### 8.3 全局数据无法查看

**问题**：系统级数据（如用户表）无法查询

**原因**：已在 CustomTenantLineHandler 中忽略这些表

**解决方案**：忽略表不需要租户过滤，如需查看使用 sys_tenant 表直接关联

## 十、配置清单

### 10.1 application.yml 配置

```yaml
# 多租户配置
know:
  tenant:
    # 是否开启多租户
    enable: true
    # 忽略租户的表（使用逗号分隔）
    ignore-tables: sys_tenant,sys_user,sys_role,sys_permission,sys_role_permission,sys_dict_type,sys_dict_data,sys_oper_log,sys_login_log
```

### 10.2 租户过滤器配置

```java
// JwtTokenInterceptor.java 中设置租户上下文
@Override
public boolean preHandle(Request request, Response response, Object handler) {
    // 获取token
    String token = getToken(request);
    if (StringUtils.isEmpty(token)) {
        return true;
    }
    
    // 解析token获取用户信息
    Long userId = StpUtil.getLoginIdAsLong();
    
    // 获取用户当前租户
    SysTenant tenant = sysTenantService.getUserCurrentTenant(userId);
    if (tenant != null) {
        // 设置租户上下文
        TenantContextHolder.setTenant(
            tenant.getId(), 
            tenant.getCode(), 
            sysTenantService.isTenantAdmin(userId, tenant.getId())
        );
    }
    
    return true;
}
```
